Ejercicio 1: Estructura HTML Básica

Objetivo: Crear la estructura semántica de un blog.

En este ejercicio, debes utilizar las etiquetas <header>, <main>, <article> y <footer> para construir una página válida en HTML5.

Ejercicio 2: Maquetación con Flexbox

Objetivo: Centrar elementos y crear una cuadrícula responsiva.

Aplica propiedades de display: flex para crear una galería de imágenes que se adapte a dispositivos móviles sin utilizar media queries.

Ejercicio 3: Manipulación del DOM en JS

Objetivo: Crear un To-Do list interactivo.

Añade un campo de texto y un botón. Al hacer clic, debes crear un nuevo elemento <li> y añadirlo a la lista existente utilizando document.createElement.

Ejercicio 4: Consumo de APIs con Fetch

Objetivo: Mostrar usuarios desde una API pública.

Haz una petición a https://jsonplaceholder.typicode.com/users y renderiza en pantalla el nombre y email de cada usuario en tarjetas separadas.
